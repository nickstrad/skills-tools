# Historical PostgreSQL guide notes

This directory preserves teaching notes and variations from the original PostgreSQL Systems course.
It is reference material only: the active `postgres` route is the generated curriculum and the
shared tutor's complete lesson view. These guide notes do not add a required review stage, pilot
stop, reading assignment, or completion step.

The former pilot runtime and renderer have been retired. The useful explanations remain available
here for authors who need historical context; new lessons should put their required mechanism,
diagram, commands, evidence, interpretation, and cleanup directly in authored curriculum content.
